## What changed (stakeholder-facing)

- **Mobile hero opens with a one-shot 360° spin** (back → front) on the `#f0f0f0` studio ground — UI hidden during playback; docked footer matches studio ground.
- **Spin plays at 2× speed** — quick intro, not a full-page takeover; asset sized like other gallery shots.
- **Slide 0 stays on the spin’s end frame** — no swap to the separate a0 still.
- **After the spin**, **UI returns in a choreographed stagger** (header → indicator → name/price → ATB → color rail).
- **Gallery scrolls vertically** on mobile (snap stack) with a **vertical tick indicator** bottom-left.
- **Desktop (`lg+`) unchanged** — same v5 two-column split layout.

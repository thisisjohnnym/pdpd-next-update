## What changed (stakeholder-facing)

- **Inline nav** — Coach wordmark + search / MENU / CART above the gallery (not overlay chrome).
- **Gallery in flow** — sits between nav and product info as a flex sibling (not a full-viewport absolute layer covering the buy box).
- **No slide indicator** — progress bar and category rail off; no ticks.
- **Thumbnail strip** — slide imagery; swipable; tap jumps the gallery.
- **Absolute color drawer** — tucked on top of product info; grows upward without pushing layout. Open swatches are solid color fills. Closed border matches background (no visible line). Replaces the bottom color sheet.
- **Drawer dismiss** — tap a color swatch, tap handle, drag handle down, or Escape.
- **No under-hero pickup / reviews** — next module is Get the highlights.
- **Pickup in Add to bag sheet** — store list lives inside the ATB confirmation tray.
- **ATB handoff** — Add to bag scrolls with the hero composition; fixed dock returns when land ATB leaves the viewport.
- **Mobile-first** — no desktop split on this route yet.

## Kyra feedback (Jul 13, 2026)

Stakeholder notes from Kyra Yip — implemented on `/v7` in place (one URL).

### Before → after

| Topic | Before | After |
|-------|--------|-------|
| Land swatches | Full horizontal rail (all colors, 36px) | **Large scroll rail** in hero footer; bottom half under fixed ATB |
| Land ATB | Docked in hero footer | **One fixed tray** (`PdpBottomActions`) — always on, no hero duplicate |
| Scroll swatches | None below hero | **Expanded photo rail** after hero scrolls away (mobile only) |
| ATB → gallery gap | ~28px meta padding stack | **Tighter meta strip** (`pt-2 pb-2`) |
| Pickup + reviews | Plain text-link rows | **Unified meta strip card** (icon + chevron / View reviews) |
| Size in color UI | Below-fold could show family size picker | **Suppressed** when `flatColorSheet` |
| Compare on recs | On | **Unchanged** — regression only |
| Fall-in framing | `object-contain` only — bag reads small on wide shells | **Contain + dynamic punch-in scale** (~1.12× width-fill, cap 1.48) — fuller bag body |

### Drawer contract (v7)

- **Animation:** slide-up tray via `pdp-bottom-sheet.ts` + `pdp-motion.ts` (380ms enter / 280ms exit)
- **Content:** flat color list only (`flatColorSheet: true`) — no Popular/Materials/Family sections
- **Caption:** no size · price line (`hideColorSheetSizePrice: true`)
- **Triggers:** `+N` on land compact row; expanded row (after scroll) opens same sheet — no duplicate “Color:” caption on expand rail
